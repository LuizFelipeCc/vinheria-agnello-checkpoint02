## O que o projeto faz

Permite cadastrar até 5 vinhos informando nome, tipo, safra e quantidade em estoque. Ao cadastrar cada vinho, aparece um alerta com as informações e a condição do estoque. No final, é exibido um relatório geral.

## Dados do cadastro

- Nome do vinho
- Tipo
- Safra
- Quantidade em estoque

## Alerta após cada cadastro

```
Vinho: [nome]
Tipo: [tipo]
Safra: [ano]
Quantidade: [quantidade]
Estoque: [condição]
```

## Como usar

Abra o arquivo `index.html` no navegador.
